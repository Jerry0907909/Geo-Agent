# 用户认证与会话管理

## 概述

本系统新增了用户认证和会话管理功能，支持：
- 用户注册和登录
- JWT令牌认证
- 对话历史持久化存储
- 多会话管理
- 搜索历史记录

## 快速开始

### 1. 配置MySQL数据库

首先需要安装MySQL并创建数据库：

```sql
-- 登录MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE geology_agent CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- （可选）创建专用用户
CREATE USER 'geology_user'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON geology_agent.* TO 'geology_user'@'localhost';
FLUSH PRIVILEGES;
```

### 2. 配置环境变量

编辑 `.env` 文件，配置数据库连接：

```env
# MySQL数据库配置
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_mysql_password
MYSQL_DATABASE=geology_agent

# JWT认证配置（请修改为安全的密钥）
JWT_SECRET_KEY=your-super-secret-jwt-key-change-in-production-123456
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 初始化数据库

```bash
# 初始化数据库表
python scripts/init_database.py

# 创建管理员账户（可选）
python scripts/init_database.py --create-admin
```

### 5. 启动服务

```bash
python start_api.py
```

## API接口说明

### 认证接口 (`/api/auth/`)

#### 用户注册

```http
POST /api/auth/register
Content-Type: application/json

{
    "username": "testuser",
    "email": "test@example.com",
    "password": "password123",
    "full_name": "测试用户"
}
```

#### 用户登录

```http
POST /api/auth/login
Content-Type: application/json

{
    "username": "testuser",
    "password": "password123"
}
```

响应：
```json
{
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIs...",
    "token_type": "bearer",
    "expires_in": 1800
}
```

#### 刷新令牌

```http
POST /api/auth/refresh
Content-Type: application/json

{
    "refresh_token": "eyJhbGciOiJIUzI1NiIs..."
}
```

#### 获取当前用户信息

```http
GET /api/auth/me
Authorization: Bearer <access_token>
```

#### 修改密码

```http
POST /api/auth/change-password
Authorization: Bearer <access_token>
Content-Type: application/json

{
    "old_password": "old_password",
    "new_password": "new_password"
}
```

### 聊天接口 (`/api/chat/`)

#### 发送消息

```http
POST /api/chat/send
Authorization: Bearer <access_token>
Content-Type: application/json

{
    "message": "什么是华北克拉通？",
    "conversation_id": null,  // 不提供则创建新会话
    "use_agent": false,       // 是否使用Agent模式
    "top_k": 5,               // 检索文档数量
    "return_sources": true    // 是否返回参考来源
}
```

响应：
```json
{
    "conversation_id": 1,
    "message_id": 2,
    "answer": "华北克拉通是中国最古老的陆块之一...",
    "sources": [
        {
            "content": "华北克拉通形成于太古代...",
            "source": "地质学概论.pdf",
            "relevance_score": 0.85
        }
    ],
    "reasoning_steps": [],
    "execution_time": 1.23
}
```

#### 获取会话列表

```http
GET /api/chat/conversations?limit=20&offset=0
Authorization: Bearer <access_token>
```

#### 获取会话消息

```http
GET /api/chat/conversations/{conversation_id}/messages
Authorization: Bearer <access_token>
```

#### 删除会话

```http
DELETE /api/chat/conversations/{conversation_id}
Authorization: Bearer <access_token>
```

#### 快速查询（无需登录）

```http
POST /api/chat/quick-query
Content-Type: application/json

{
    "message": "什么是板块构造？",
    "use_agent": false,
    "top_k": 5
}
```

## 数据模型

### 用户表 (users)

| 字段 | 类型 | 说明 |
|-----|------|-----|
| id | INT | 主键 |
| username | VARCHAR(50) | 用户名（唯一） |
| email | VARCHAR(100) | 邮箱（唯一） |
| hashed_password | VARCHAR(255) | 加密密码 |
| full_name | VARCHAR(100) | 全名 |
| is_active | BOOLEAN | 是否激活 |
| is_superuser | BOOLEAN | 是否管理员 |
| created_at | DATETIME | 创建时间 |
| last_login | DATETIME | 最后登录 |

### 会话表 (conversations)

| 字段 | 类型 | 说明 |
|-----|------|-----|
| id | INT | 主键 |
| user_id | INT | 用户ID |
| title | VARCHAR(200) | 会话标题 |
| summary | TEXT | 会话摘要 |
| is_active | BOOLEAN | 是否有效 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 消息表 (messages)

| 字段 | 类型 | 说明 |
|-----|------|-----|
| id | INT | 主键 |
| conversation_id | INT | 会话ID |
| role | VARCHAR(20) | 角色（user/assistant/system） |
| content | TEXT | 消息内容 |
| metadata | JSON | 元数据（来源、推理步骤等） |
| tokens_used | INT | Token消耗 |
| created_at | DATETIME | 创建时间 |

## 安全说明

1. **JWT密钥**：请务必在生产环境中使用强随机密钥
2. **密码存储**：使用bcrypt加密存储
3. **令牌有效期**：
   - Access Token: 30分钟
   - Refresh Token: 7天
4. **CORS配置**：生产环境请限制允许的源

## 故障排除

### 数据库连接失败

1. 检查MySQL服务是否运行
2. 检查`.env`中的配置是否正确
3. 确保数据库已创建

### 认证失败

1. 检查令牌是否过期
2. 使用刷新令牌获取新的访问令牌
3. 确保请求头格式正确：`Authorization: Bearer <token>`

### 性能优化

1. 启用Redis缓存（配置`REDIS_HOST`）
2. 调整连接池大小
3. 使用混合检索提高准确性
